Mettre à jour le site

Modifie les textes, les prix, l'ordre des cours ou les informations de contact ci-dessous, puis clique sur « Télécharger content.json » en bas de page. Remplace ensuite ce fichier sur le serveur du site (à côté d'index.html) pour publier les changements.

Les champs marqués d'un * sont obligatoires. Pour les images, indique uniquement le nom du fichier (ex. chien.jpg) : le dossier est ajouté automatiquement.
